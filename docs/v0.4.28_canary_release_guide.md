## 2. リリース実行手順

```bash
# 1. バージョン更新
cd episodic-claw
npm version patch --no-git-tag-version   # 0.4.27 → 0.4.28

# 2. ビルド確認
npm run build:ts

# 3. テスト確認
npx tsx test_runtime_mode_detection.ts
npx tsx test_narrative_quality_gate.ts
npx tsx test_config_pipeline.ts

# 4. コミット ＆ タグ
git add -A
git commit -m "release: publish v0.4.28"
git tag v0.4.28

# 5. プッシュ
git push origin main --tags
```

> **注意**: npm publish / GitHub Release 作成はプロジェクトの CI/CD または ClawHub 手順に従うこと。

## 3. Canary 観測手順

### 3.1 観測期間

| 時点 | チェック内容 | 判定基準 |
|------|-------------|----------|
| **+0h**（リリース直後） | プロセス起動確認 | gateway/agent/test が正常起動 |
| **+1h** | ログ洪水抑制確認 | `"CLI mode detected"` 出力 0件 |
| **+24h** | 第1チェック — d 系確認 | 下記 §3.2 の d 系チェック全通過 |
| **+48h** | 第2チェック — a/b/c 系確認 | 下記 §3.3 の a/b/c 系チェック全通過 |

### 3.2 d 系チェック（+24h 時点）

| # | チェック項目 | コマンド | 期待結果 |
|---|-------------|----------|----------|
| D1 | skip ログ洪水が抑制されている | `grep "CLI mode detected" openclaw-*.log \| wc -l` | **0件**（`EPISODIC_LOG_CLI_SKIP=1` 未設定時） |
| D2 | JSON runtime-mode event が各 daemon から1回出力 | `grep '"event":"runtime-mode"' openclaw-*.log` | gateway/agent/test 各1行 |
| D3 | gateway probe 成功率が Canary 前と同等以上 | `openclaw gateway probe` | 成功（timeout なし） |
| D4 | node プロセス CPU が Canary 前と同等以下 | `ps -p $(pgrep -f "openclaw.*node") -o %cpu` | ≤ Canary 前実測値 |
| D5 | `EPISODIC_LOG_CLI_SKIP=1` 復元が機能する | `EPISODIC_LOG_CLI_SKIP=1 openclaw node -e "console.log('test')"` | skip ログ1行出力 |

### 3.3 a/b/c 系チェック（+48h 時点）

| # | チェック項目 | コマンド | 期待結果 |
|---|-------------|----------|----------|
| L1 | Language Guard softwarn ログに誤検知なし | `grep "language.*softwarn\|language.*mismatch" openclaw-*.log` | 件数が妥当（0〜数件/日） |
| L2 | 物語 reject 率が Canary 前と同等以下 | `grep "quality.*reject\|gate.*reject" openclaw-*.log \| wc -l` | Canary 前以下 |
| L3 | reask/handoff が正常動作 | `grep "reask\|handoff" openclaw-*.log` | handoff 先で物語生成成功 |
| L4 | 物語品質（体感）が低下していない | 目視確認 | 著しい品質低下なし |

## 4. Canary 卒業判定

### 4.1 卒業条件（全て満たすこと）

- ✅ D1〜D5 全通過
- ✅ L1〜L4 全通過
- ✅ 新規インシデントなし
- ✅ CPU/メモリ推移に異常なし

### 4.2 卒業時アクション

```markdown
1. プラン PASSOFF の canary チェックボックスに ✅ を付ける
   - v0.4.28a: 「1日観測ログ採取（softwarn件数）」
   - v0.4.28d: 「canary 24h 観測（skip文言件数 / probe 成功率 / CPU）」
2. 本ドキュメントの Status を 🟢 CANARY GRADUATED に更新
3. v0.4.28 を安定版扱いとする
```

### 4.3 Canary 失敗時のロールバック

```bash
# v0.4.27 へのロールバック
git checkout v0.4.27
npm run build:ts
# 再デプロイ
```

**ロールバック判断基準**:
- gateway probe timeout が Canary 前より悪化
- 物語 reject 率が Canary 前の2倍以上
- CPU が Canary 前の1.5倍以上で48h持続
