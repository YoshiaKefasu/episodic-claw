## 🐛 Post-Implementation Bug Fixes — 2026-04-23
> Found during thorough regression review before advancing to v0.4.28b

### BUG#1 — `detectLanguageDetailed()` 二重 eld.detect() 呼出し 🔴
**Problem**: `detectLanguage()` 内部で `eld.detect(text)` を呼び、その後 `detectLanguageDetailed()` でもう一度 `eld.detect(text)` を呼ぶ — 200KB テキストの二重処理。
**Root cause**: DRY コメントは「ロジック重複を避ける」と書いていたが、実際には高コストな eld.detect() だけが重複していた。
**Fix**: `detectLanguageDetailed()` から `detectLanguage()` 呼出しを削除。`eld.detect()` を1回だけ呼び、同じ結果から lang・confidence・isReliable を全て導出。
**DRY fix**: 言語正規化 switch を `normalizeEldLang()` に抽出 — `detectLanguage()` と `detectLanguageDetailed()` で共有。

### BUG#2 — ms→id confidence スコア検索キー不整合 🔴
**Problem**: eld は Indonesian/Malay のスコアを内部キー `'ms'` で保存する。しかし `detectLanguage()` は `'ms'` → `'id'` に正規化。前のコードは正規化後の `'id'` でスコアを検索 → `scores['id']` は常に `undefined` → confidence 常に 0 → **インドネシア語の言語ガードが一切効かない**。
**Fix**: `rawLang`（eld の内部キー、例: 'ms'）でスコア検索。正規化後の `lang`（'id'）は戻り値用のみ。
```typescript
const scoreLookupKey = rawLang; // 'ms' for Indonesian
const confidence = scores[scoreLookupKey] ?? 0;
```

### BUG#3 — onFail='reask'|'handoff' サイレントフォールスルー 🟡
**Problem**: config は `reask`/`handoff` を受け付けるが、実装は未完了でサイレントにフォールスルー。ユーザーが `onFail: 'reask'` を設定しても何も起こらず、リトライもハンドオフも無い。
**Fix**: 明示的 warning + softwarn フォールバック。v0.4.28c で実際の reask/handoff を実装するまで softwarn 扱い。
```
onFail='reask' is not yet implemented (planned for v0.4.28c). Treating as softwarn.
```

### BUG#4 — G0 softwarn early return が後続 Gate 1-4 をバイパス 🚨 CRITICAL
**Problem**: 言語ミスマッチ + softwarn の時、G0 が即座に `return { pass: true, ... }` で返っていた。この early return により、**圧縮率（Gate 1）・エコー検出（Gate 2）・フォーマット（Gate 3）・アンカー網羅（Gate 4）が全てスキップ**される。言語不一致のテキストが圧縮率不足や verbatim echo でも通過してしまう致命的な回帰。
**Root cause**: softwarn = 「保存は止めない」という意図を「gate を pass として即完了」と誤実装。softwarn は「観測のみ」であり、後続 gate の評価を止めるべきではない。
**Fix**: softwarn / 未実装 onFail の両方で early return を削除。warning ログ + 観測 event を出力した後、**fall-through** して後続 gate が通常通り実行されるように変更。
```typescript
// BEFORE (BUG#4): early return bypassed all downstream gates
return { pass: true, reason: "narrative-language: mismatch-softwarn", isContentGate: true };
```

### P1 fix — `confidence` の `Number.isFinite()` ガード追加 ✅
**File**: `src/lang-detect.ts` L94-100
**Problem**: `eld.getScores()` が NaN や Infinity を返した場合、`NaN >= threshold` は常に `false` → 言語ミスマッチが検出されず softwarn も出ない。
