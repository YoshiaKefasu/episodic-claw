# v0.4.32 — Deprecated config schema cleanup

> **作成日**: 2026-05-24  
> **ステータス**: Completed  
> **目的**: `openclaw.plugin.json` の `configSchema` から、runtime で使われていない deprecated / compatibility キーを整理する。  
> **スコープ**: Episodic-Claw のみ。DennouAibou / OpenClaw core は変更しない。

---

## A. 結論

今の `configSchema` には、**見えているけど使っていないキー** と、**まだ互換のために残しておくキー** が混ざっている。

この cleanup では、**完全に schema-only になっているキー** を落とし、あわせて runtime で使っていない `maxBufferChars` と `maxPoolChars` を schema / types / config / tests から消す。既存設定にまだ残っている場合は、次回読み込み時に schema validation で落ちる。

**C1-C2 は実装済み**。`sharedEpisodesDir`、`allowCrossAgentRecall`、`maxBufferChars`、`maxPoolChars` は削除した。

---

## B. 読んだ証拠

### B1. schema-only の dead key はすでに削除済み

`openclaw.plugin.json` と `src/index.ts` から削除済み:

- `sharedEpisodesDir`
- `allowCrossAgentRecall`

意味: どちらも schema にはあるだけの飾りだったが、`src/types.ts` の `EpisodicPluginConfig` には存在せず、`src/config.ts` でも読まれていなかった。runtime に効かないので、実際に削除した。

### B2. `maxBufferChars` と `maxPoolChars` は runtime で使われていない

`openclaw.plugin.json:48-56`、`src/index.ts:496-503,577-580`、`src/config.ts:115,178`、`src/types.ts:87-93,152-153`、`src/index.ts:836-843`:

- schema / type / config loader / test assertion から削除済み
- runtime 側でも `EventSegmenter` / `NarrativePool` から参照を外した

意味: これは見た目の互換キーではなく、完全に死んだ設定だった。消しても runtime の中心は壊れない。

### B3. `maxCharsPerChunk` と `openrouterConfig` はまだ生きている

`src/config.ts:115-116, 137-173`、`src/segmenter.ts:1088-1090`、`src/index.ts:605-622`:

- `maxCharsPerChunk` は segmenter が実際に使っている
- `openrouterConfig` は `loadConfig()` がまだ読み、`narrativeConfig` の互換 fallback になっている

意味: ここは cleanup 対象ではない。今切ると runtime が壊れる。
