## 5. 実装計画（Fix A〜G）

### Fix A — Validator Chain 実行モデルへ整理
- 既存の `applyQualityGates()` を段階的に validator chain へ整理。
- `GuardDecision` / `OnFailAction` 相当を内部型で導入。
- 既存 reject reason 互換を維持（ログ解析互換）。

### Fix B — MiniGuard本体（G5/G6/G7）

#### B-1: G5 Minimum Sentence Gate
- CJK: `>=3` 文
- Latin: `>=4` 文
- reason: `narrative-content: too-few-sentences`

#### B-2: G6 Minimum Content Floor
- CJK: `>=120` chars
- Latin: `>=80` words
- reason: `narrative-content: too-short-content-floor`

#### B-3: G7 Corrective Feedback Classifier
- fail reason に応じて次試行 prompt 末尾へ補正ヒントを注入。
- 例:
  - `too-short-content-floor` → 具体例3件を要求
  - `low-anchor-coverage` → ファイル名/コマンド/数値を3件以上要求

### Fix C — `contentGateEnabled=false` 経路の回帰防止
- `contentGateEnabled=false` 時:
  - B系（G5/G6/G7）は **softwarnのみ**
  - 保存阻害をしない
- 目的: item-loss 回帰防止（v0.4.27b の設計意図維持）

### Fix D — 言語ガード G0 追加（configSchema連動）
- `applyQualityGates()` 先頭に G0 を追加。
- `narrativeExpectedLanguage` が `auto` 以外なら言語一致を検証。
- mismatch 時に `onFail` 分岐:
  - `reask` / `handoff` / `softwarn` / `exception`

### Fix E — configSchema + types + config ロード

#### E-1 `openclaw.plugin.json`
追加キー:
- `narrativeExpectedLanguage` (`auto|ja|en|zh|ko|id`)
- `narrativeLanguageThreshold` (0..1, default 0.75)
- `narrativeLanguageOnFail` (`reask|handoff|softwarn|exception`)

#### E-2 `src/types.ts`
`EpisodicPluginConfig` に上記3項目 + MiniGuard閾値設定を追加。

#### E-3 `src/config.ts`
clamp/default適用:
- expected: `auto`
- threshold: `clampUnitInterval(..., 0.75)`
- onFail: invalid時 `reask`

### Fix F — `lang-detect` 詳細化
- `detectLanguageDetailed()` を追加し、`{ lang, confidence }` を返す。
- G0で threshold を利用。
- confidence が不安定な入力は `unknown` 扱い + onFail分岐。

### Fix G — テスト追加

#### G-1 `test_narrative_quality_gate.ts`
1. too-few-sentences
2. too-short-content-floor
3. corrective feedback reason分岐
4. expected=ja / output=en mismatch
5. expected=en / output=ja mismatch
6. expected=auto pass
7. onFail=softwarn pass
8. onFail=handoff phase移行

#### G-2 `test_config_pipeline.ts`（必要時）
1. 新configキーのdefault
2. clamp挙動
3. invalid値フォールバック

## 7. リスクと対策

| リスク | 影響 | 対策 |
|---|---|---|
| 過検知で保存率低下 | 中 | softwarn先行→段階hard化 |
| CJK/Latin混在誤判定 | 中 | threshold + unknown分岐 + KPI監視 |
| retry増加 | 低〜中 | early handoff維持 / 既存上限内で制御 |
| contentGate無効経路の回帰 | 高 | `contentGateEnabled=false`でsoftwarn固定 |
