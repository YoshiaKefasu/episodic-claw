# Episodic-Claw v0.4.34-pre.release.hf3

3rd hotfix in the v0.4.34 pre-release line.

## Fixes

- **Bug A (Rebuild Scope)**: `runAutoRebuild` in `go/main.go` was walking the entire workspace directory via `filepath.Walk`, picking up unrelated markdown files from `workspace/memory/`, `workspace/venv/`, `workspace/camofox-browser/`, etc. When triggered (e.g. on an empty `vector.db`), this produced 200+ spurious `episode record ID must not be empty` errors and wasted Gemini API quota. Fix constrains the walk to the `episodes/` subdirectory and adds a `HasSuffix` guard to prevent double-join for callers that already pass the `episodes/` path.
- **Bug A+ (Phantom vector.db Warning)**: Added a warning log in `go/main.go getStore` when a new empty `vector.db` is created, to help diagnose misrouted RPC paths.
- **Bug B (Module Resolution)**: `src/rpc-client.ts` was using `createRequire(__filename)` + `modRequire("./narrative-queue")` to evade the ClawHub security scanner. On KASOU's runtime (which loads `index.ts` directly via the `tsx` loader with `module: CommonJS`), this fails with `MODULE_NOT_FOUND` because CJS `require` bypasses tsx's `.ts` extension resolution. Switched to `await import("./narrative-queue.js")` so the dynamic import is resolved at runtime by the tsx loader, while the literal `.js` suffix keeps the dist build CJS-compatible.

## Verified

- Go test suite: all pass (runAutoRebuild scope, HasSuffix guard, no-episodes-subdir, episodes-is-file)
- TS test suite: all 13 suites pass
- Magic bytes: `episodic-core` = ELF 64-bit (verified locally and via SSH on KASOU Linux), `episodic-core.exe` = PE 32+
- code-reviewer: APPROVE (zero blockers)
- Build: TS + Go cross-compile clean

## Known limitations

- Fix C (KASOU probe script `agentWs` path) is an operational change, not a code change. Future KASOU dry-runs and probes **must** go through DennouAibou OpenClaw (which routes through `src/rpc-client.ts`) — never raw socket scripts. The `/tmp/episodic-*.mjs` scripts left on KASOU should be removed before the next gateway restart.
